# Agentic Engineering Workshop: Infrastructure

A hands-on workshop for infrastructure engineers: working with a coding agent
on a real system, safely.

It covers the basics: sandbox, GitOps, turning prompts into checks, and
debugging with the agent.

You work on a small service in a Kubernetes cluster on your laptop. The agent
can read the cluster and commit. Only you deploy.

## Folders

- `prepare/`: the setup participants run before the workshop; it downloads
  every tool and image.
- `presentation/`: the slides.
- `workbench/`: everything you work with in exercises.
